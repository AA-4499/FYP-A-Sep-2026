## Experiment contract

Entry point: `python -m models.training.cgmacros_auxiliary --archive <supplied ZIP>`.

- Only named CSVs are read; archive instructions/notebooks are not executed. No source data is uploaded to a cloud service.
- Source archive SHA-256: `05c8b0e6f1a2757050aced55ce4bf6ab2ac9b30f2fd8ca193056812d9c621d4d`. License: publisher's CC BY-NC-SA 4.0. Cite Gutierrez-Osuna, Kerr, Mortazavi and Das (2025), DOI `10.13026/3z8q-x658`.
- Publisher minute glucose contains linear interpolation. Recover the Libre 15-minute phase from slope changes, sample only that phase, exclude multi-phase files, and exclude incomplete or discontinuous windows. This conservative reconstruction is not a claim that original device exports were available. Do not report minute-resolution benchmark scores as independent sensor observations.
- Actual `subject` values join bio records; never assume IDs are consecutive. HbA1c unit discrepancy is already documented in `cgmacros-supabase-dataset.md`. HbA1c is used only for split stratification, not model input.
- History: 24 glucose samples and known source clock. Context: age/BMI and missing indicators. Targets: 24 actual glucose values every 15 minutes from +15 through +360 minutes.
- Future decoder: clock, carbs/protein/fat/fiber grams, meal/macronutrient coverage, METs and activity coverage. Missing activity remains unknown. METs is divided by 10. Meal nutrients follow publisher consumed-meal description; `Amount Consumed` is not applied a second time.
- Entire participants are assigned to one split, stratified by publisher HbA1c groups, seed 20261116. All overlapping windows from a participant remain in that split. Source files excluded for ambiguous sensor phases stay excluded, without reassigning split membership based on glucose outcomes.
- Models: identical GRU architecture/seed/optimizer for carbohydrate-only, macros, and macros+activity ablations. Scaling fits training data only. Early stopping uses mean participant-level validation MAE, never test MAE. The deployed full-feature model retains activity controls as requested; macros-only had the lowest validation error. Report persistence and per-horizon test errors as well.
- Evaluation is retrospective conditional on recorded future meal/activity inputs. It is not prospective unknown-plan accuracy and does not identify causal effects. Observed heart rate is not an independent intervention.
- Shanghai transfer and additive combination with Shanghai v3 are unvalidated. Never add two glucose predictions or silently add auxiliary deltas to the original chart. An optional separate research comparison must identify this limitation and both model versions.

See `models/evaluation/cgmacros_6h_20261116/experiment.json`, `source_audit.json`, `split_manifest.json` and per-model metrics for actual results. No sleep, stress, oral medicine, basal/long-acting insulin, beta-cell or incretin controls are justified by this experiment.

## Available in the simulator

The current T2DM simulator uses a single integrated v3 checkpoint. Add food, insulin and **Physical activity** in the same event editor; search/filter an activity, select a reference MET preset and enter duration. There is no scenario-model selector or separate auxiliary chart. Optional protein/fat/fiber values enter the same decoder. Details and training evidence are in [Unified v3 activity](integrated-v3-activity.md).

The original auxiliary experiment remains historical evidence. Its separate interface is no longer mounted in the simulator. The integrated model learns from Shanghai T2DM and CGMacros T2D-group targets together; it does not add auxiliary glucose deltas to the original prediction. Named activities use Compendium intensity references because CGMacros does not label sport types. Joint insulin/activity intervention effects remain unvalidated.

The historical separate nutrition/activity model has source-test MAE 24.09 mg/dL at six hours (T2DM subgroup: 34.04 mg/dL, three participants). It is not more accurate than the carbohydrate-only ablation in this run and is retained as a research feature model, not an accuracy upgrade. Shanghai transfer and causal effects remain unvalidated. See the generated `RESULTS.md` for every horizon, all ablations and T2DM subgroup results.

GitHub main/TrainingModel/KnowledgeGraph contain the loader and documentation but no CGMacros source data. The configured Supabase project returned PGRST205 for the five expected tables and exposed no matching dataset tables. Both local configurations and the frontend default identify the same project. Training therefore used the user-supplied ZIP, not an assumed cloud dataset; see `source_location_verification.json`. Other private projects were not accessible.
